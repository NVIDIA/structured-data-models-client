## Description: <br>
Ask kumo-relational a question about an entity and the records linked to it: write the question as a predictive query over a schema of related tables, covering classification, regression, forecasting and link prediction. <br>

This skill is ready for commercial/non-commercial use. <br>

## Owner
NVIDIA <br>

## Use Case: <br>
Developers and data scientists use this skill with coding agents to write Python that describes related tables (in memory or in a warehouse) and asks NVIDIA's kumo-relational structured-data foundation model predictive queries about entities through the structured-data-models client, without training a model. <br>
