## Description: <br>
Ask kumo-tabular a question about rows of one table: classification or regression over labelled rows and rows to score, with no relationships and no time windows. <br>

This skill is ready for commercial/non-commercial use. <br>

## Owner
NVIDIA <br>

### License/Terms of Use: <br>

## Use Case: <br>
Developers and data scientists use this skill with coding agents to write Python that asks NVIDIA's kumo-tabular structured-data foundation model to classify or regress rows of a single table through the structured-data-models client, without training a model. <br>
