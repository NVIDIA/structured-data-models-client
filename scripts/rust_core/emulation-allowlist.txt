# The modules allowed to emulate Python behavior, one path per line, relative
# to the repository root (Phase 1 design, "PQL parser"; decisions A4
# and E9).
# Emulation is banned everywhere else; each addition needs an owner-approved
# decisions row (H21), and the list is permanent, with no expiry (E18). The
# vocabulary scan (T1.10c) reads it.
#
# The line: emulation is copying a library's incidental behavior, such as a
# codec or a repr. Porting an algorithm the reference itself defines is a
# port, with a row in docs/design/rust-core/phase-1/dependencies.md, not an
# entry here: DateOffset arithmetic in sdm-pql's dor.rs, str.isspace
# in syntax.rs, the query[:-1] quirk in visitor.rs, and T1.25's
# sdm-engine::time::text_shapes.

# Python's 4,300-digit limit on reading an integer, which decides validity.
rust/crates/sdm-pql/src/pyint.rs
# The text Python's repr gives a float, and from T3.5 the repr and str of the
# values a view's conversion messages quote (Shown, text_repr).
rust/crates/sdm-pql/src/float_repr.rs
# How the reference reads a string literal's escapes, which decides validity
# (Phase 1 decisions, E9).
rust/crates/sdm-pql/src/escapes.rs
# The conversions a view's parameter default goes through, Python 3.12's
# int(), Decimal formatting and fromisoformat, which decide whether a
# default is a value of its type (T3.5 fix 2). Approved by owner: T35-OWNER-2026-10-24-EMULATION (original item 7).
rust/crates/sdm-pql/src/conversions.rs
# Python 3.12's printable code points (str.isprintable), the table a repr
# escapes by, generated from Python by contract/fixtures/views/gen_printable.py
# (T3.5 fix 3). Approved by owner: T35-OWNER-2026-10-24-EMULATION.
rust/crates/sdm-pql/src/printable.rs
