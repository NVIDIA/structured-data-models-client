# JNI license files

The published `jni` 0.22.4 crate omits its license files.
These unchanged files come from [the exact upstream source commit](https://github.com/jni-rs/jni-rs/tree/5ae9458a4ec44c5318f37ddc7569c1d4ae8a69e7), as recorded in the crate's `.cargo_vcs_info.json`.
`scripts/rust_core/rust_notices.py` includes them when generating attribution for the JNI library.
