This is the bounded follow-up to the executed R40 native-profile failures.
The implementation remains inside the existing schema, engine, request, wire, core and host crates.
Python retains actual native conversion effects; Rust retains label, mask, quota, sampling and request policy.
No new behavior difference, callback-bearing RunStep, generic interpreter, continuation cursor or native library/version policy is approved by this plan.
